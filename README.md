# Yusaf Dental Practice

A responsive, dependency-free website for Yusaf Dental Practice on University Road, Peshawar. Custom local SVG artwork; no stock clinic or doctor photos, fabricated reviews, ratings, or unverified qualifications.

## Run locally

From this folder, run `python3 -m http.server 4173 --directory dist` and open http://localhost:4173.

## Deploy

Import this repository into Vercel. Framework preset: Other. Output directory: `dist`. No installation or build command is required. Configuration is in `vercel.json`.

## Appointment enquiries

The form validates the visitor's name, prepares an encoded WhatsApp message, and opens WhatsApp. Nothing is sent automatically. It does not store submissions or create confirmed bookings. Telephone and directions links also work without JavaScript. Confirm WhatsApp is enabled on the published mobile number with the clinic before launch.
